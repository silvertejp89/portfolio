# Kriss Stockhaus – Portfolio

My personal portfolio: who I am, the technologies I work with, and a selection of projects.
I'm a full-stack developer moving into application security.

**Live:** https://krissportfolio.netlify.app

## Tech

React (Create React App), JavaScript, CSS. Project data lives in `src/assets/data/` and is rendered by small components.

## Run locally

```bash
npm install --legacy-peer-deps
npm start
```

`--legacy-peer-deps` is needed until the lockfile is updated.
